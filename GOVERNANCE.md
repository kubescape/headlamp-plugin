# Governance

The Kubescape Headlamp plugin follows the [Kubescape project governance](https://github.com/kubescape/project-governance/blob/main/GOVERNANCE.md), which is the authoritative source for decision-making processes, community roles, and maintainer selection.

## Maintainers

Repository maintainers are listed in [OWNERS](./OWNERS). Maintainers review and merge pull requests, manage releases, ensure the quality and stability of the plugin, and provide direction and priorities. Triagers help organize issues and pull requests; merging remains the responsibility of maintainers.

## Decision making

Discuss proposed changes in an issue in this repository. Once there is consensus, submit a pull request following [CONTRIBUTING.md](./CONTRIBUTING.md), including a Developer Certificate of Origin sign-off on every commit. Changes require at least one approving review before merging.

Participants should first try to resolve disagreements together. Unresolved conflicts are escalated to the maintainers, whose decision is final under the Kubescape project governance.

Changes to the organization-wide governance follow the contribution process in the [project-governance repository](https://github.com/kubescape/project-governance).
