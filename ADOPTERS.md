# Adopters

This list records users and organizations that publicly identify themselves as using the Kubescape Headlamp plugin, whether in production or during evaluation.

No plugin-specific adopters have registered in this list yet.

For adopters of the wider Kubescape project, see the [Kubescape adopters list](https://github.com/kubescape/project-governance/blob/main/ADOPTERS.md). Entries in that list do not necessarily indicate use of the Headlamp plugin.

## Register as an adopter

1. Submit a pull request to this repository adding a row to the table above. Only list yourself or an organization you are authorized to represent.
2. Include your organization or user name, a public website if available, and a short description of how you use the plugin. Contact information is optional; only provide information you consent to publish.
3. Keep entries in alphabetical order by organization or user name. When adding the first entry, remove the sentence stating that no adopters have registered.
4. Follow [CONTRIBUTING.md](./CONTRIBUTING.md) and include a DCO sign-off on every commit with `git commit -s`. Maintainers review submissions before merging.

To update or remove your entry, submit a pull request following the same process.
